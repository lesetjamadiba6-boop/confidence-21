CHAPTER 21 — CONFIDENCE
Launch-ready build

1. KEEP THIS FOLDER STRUCTURE EXACTLY AS IT IS

confidence-21-launch-ready/
  index.html
  style.css
  script.js
  images/
  music/
    chapter-21-theme.mp3

Do not move the images or music file out of their folders unless you also update the paths in the code.

2. TEST LOCALLY IN VS CODE
- Open the whole folder in VS Code.
- Install the Live Server extension if you do not have it.
- Right-click index.html -> Open with Live Server.
- Click "Open Chapter 21". The soundtrack is designed to begin from this click because browsers normally block audio that starts without user interaction.
- Test the photo album, 21 cards, Open When letters and final celebration.

3. IF YOU DO NOT HEAR MUSIC
- Confirm music/chapter-21-theme.mp3 exists.
- Make sure the browser tab/site is not muted.
- Click the round music control at the bottom-left after opening the gift.
- Refresh with Ctrl + Shift + R if the browser cached an older version.

4. PUBLISH WITH GITHUB PAGES
- Create a new public GitHub repository, for example: confidence-chapter-21
- Upload index.html, style.css, script.js, the images folder and the music folder to the root of the repository.
- Open repository Settings -> Pages.
- Choose Deploy from a branch.
- Select the main branch and /root, then Save.
- GitHub will provide a public link after deployment finishes.

Important: upload the CONTENTS of this folder to the repository root so index.html is at the top level.
